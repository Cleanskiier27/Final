# Privacy Policy — NetworkBuster Discord Bot

_Last updated: 2026-09-01_

## 1. Data We Process
When you use a slash command, Discord sends the Bot an interaction payload containing: your Discord user ID, the server (guild) ID, the channel ID, and the command name/options you supplied. This data is processed only to generate the command's response.

## 2. Data We Store
The Bot does not persist interaction payloads, message content, or user data to a database. Application logs may transiently include timestamps and command names for operational debugging and are not retained long-term or shared with third parties.

## 3. Data We Do Not Collect
The Bot does not read message content outside of slash command interactions, does not track user activity across servers, and does not sell or share data with advertisers or third parties.

## 4. Third-Party Services
The Bot communicates only with Discord's API to receive and respond to interactions. No other third-party services receive user data.

## 5. Your Rights
Since no persistent personal data is stored, there is no user data to request deletion of beyond removing the Bot from your server, which stops all further data processing.

## 6. Changes
This policy may be updated at any time; the "Last updated" date above reflects the most recent revision.

## 7. Contact
Questions about this policy can be directed to the server owner who invited the Bot.
